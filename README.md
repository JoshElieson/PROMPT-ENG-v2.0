# FORGE

FORGE is a desktop AI engineering IDE for working with multiple AI models, project files, prompts, and agent-style workflows in one focused workspace.

The app is designed for developers who want more control over AI-assisted coding: persistent project context, multi-model conversations, file-aware prompting, and a workspace built around engineering tasks rather than general chat.

## Why I Built It

I wanted to explore what an AI-native development environment could look like beyond a normal chatbot. FORGE is my attempt to build a more structured AI engineering workspace: one that combines desktop performance, local file access, multi-model prompting, project organization, and agent-style collaboration.

## Features

- Desktop app built with Tauri
- Multi-model AI chat interface
- Project and workspace organization
- File-aware prompting and context management
- Multi-pane workspace layout
- Prompt engineering tools
- Agent-style conversation workflows
- Modern React-based interface
- Native desktop packaging and installer support

## Tech Stack

- **Desktop:** Tauri
- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Native Layer:** Rust
- **State / UI:** Component-based React architecture
- **AI Integration:** Multi-provider AI model support
- **Deployment:** Desktop build and installer pipeline

## Engineering Highlights

- Built a cross-platform desktop app using Tauri and Rust
- Designed a multi-pane workspace for AI-assisted engineering workflows
- Implemented project/file context to make AI responses more useful for coding tasks
- Structured the app around reusable workspace, chat, and model-provider components
- Created a foundation for multi-agent collaboration and prompt orchestration
- Balanced frontend UX with native desktop capabilities and security constraints

## What I Learned

FORGE strengthened my understanding of desktop app development, AI tooling, file-context systems, frontend architecture, and product design for developer tools. It also pushed me to think deeply about how AI can fit into real engineering workflows rather than just act as a chat interface.
